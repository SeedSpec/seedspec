# Use cases

> Informative. These are realization shapes, not package kinds and not
> markets.

Capable agents can do many bounded tasks without a SeedSpec. The format
is for intent that must travel: across people, systems, time, or stacks.

## Realization

### New application

Package the behavior, configuration, and observable success. The adopter
chooses a stack. The agent builds and records evidence.

### Feature in an existing product

Package reusable behavior and the host concepts it needs. The host keeps
its names. The agent inspects the actual product, maps equivalent
concepts, and adapts the feature. The spec does not force the source
package's architecture or screens.

### Configured state in an existing system

The result is durable state in another product, not a new codebase. The
package supplies meaning, permissions, constraints, and observable
success. Validation does not authorize sign-in or writes.

### Cross-system automation

Trigger, meaning of the data, recipients, failure, and evidence — without
requiring one orchestration technology.

### Composite

A new surface plus configured systems plus recurring operations. Same
package format. Different realizations.

### Short-lived tool

A temporary dashboard or review artifact. The implementation may be
disposable. The intent can still be reused.

## Distribution

The protocol makes a package identifiable and checkable. It does not
decide who is allowed to publish, which catalog an organization approves,
or what anything costs.

An internal catalog, a consultancy, a vendor, or an independent author
can all ship the same kind of object. Catalog authority is organizational.
Vendor-specific guidance is supporting context. Neither is protocol
conformance, and neither is execution authority.

## Where it is worth the cost

Value grows when the result crosses systems, depends on private or
unfamiliar platforms, has important edge cases, or is expertise worth
reusing. It is not a substitute for a capable agent. It is a better
starting state when the destination would otherwise be inferred.
