# Approved workflow brief

The outcome is one dependable morning incident briefing for each configured
team. It covers incidents that are open when the briefing is prepared. Each
entry gives severity, owner, and next action.

Schedule, source authority, and retry identity need explicit author decisions.
After those decisions, the primary intent, configuration guide, and acceptance
material must tell one coherent story. A later agent must not reopen settled
answers merely because its conversation context is fresh.
